## Who this is for

A new [[ops-analyst]] — someone with free-tier tooling only who needs to make one recurring task repeatable this week.

## Outcome

After completing the sequence, the person can standardize one recurring analysis with a reusable prompt block, hand that block to a teammate, and build a working single-file calculator whose numbers they have verified against a known case.

## Sequence

Concepts come before the procedures that need them.

1. **concepts/system-prompt.md** (basic, ~10 min) — what a fixed instruction block is and why it goes first.
2. **procedures/create-data-audit-prompt-block.md** (basic, ~20 min) — build the first reusable block and see the pattern work.
3. **procedures/share-prompt-blocks-with-team.md** (basic, ~15 min) — make the block the team's standard, not a personal trick.
4. **concepts/single-file-web-app.md** (basic, ~10 min) — why one HTML file is a deliverable software artifact.
5. **procedures/build-roi-calculator-copilot-free.md** (intermediate, ~45 min) — generate a tool, then verify it with the known case before trusting it.

Total: about 100 minutes. Steps 2 and 3 produce a real artifact (the block file in the shared folder); step 5 produces a real file (the calculator). Both are checkable by someone other than the learner, which is what makes this a path rather than a reading list.
